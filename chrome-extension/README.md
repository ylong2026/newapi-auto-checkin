# NewAPI 多站自动签到 · Chrome 扩展版

浏览器插件，本地加载即可使用。支持开启了 Turnstile / Cloudflare WAF 的 NewAPI 中转站。

## 安装方法

1. 打开 Chrome（或 Edge），地址栏输入 `chrome://extensions/`
2. 右上角打开「开发者模式」
3. 点左上角「加载已解压的扩展程序」
4. 选择本文件夹（`chrome-extension`）
5. 扩展图标会出现在工具栏，建议固定到工具栏

## 使用方法

### 1. 添加站点

点扩展图标打开弹窗，在「站点」标签页填写：
- **站点名称**：随便起，自己好认
- **站点网址**：如 `https://tabitoken.com`，末尾不要加斜杠
- **系统访问令牌**：登录站点后，右上角头像 → 个人设置 → 安全设置 → 系统访问令牌 → 生成/重新生成，复制整串
  - ⚠ 不是左侧「令牌」菜单里调用大模型的 Key
- **数字用户 ID**：个人设置页显示的纯数字 ID，建议填写

### 2. 测试签到

点站点右侧的「签到」按钮，会弹窗显示结果。

### 3. 自动签到

- 扩展会在每天北京时间 0~23 点之间随机选一个整点自动签到
- 多个站点间隔 3~15 秒
- 遇到 Turnstile 或 WAF 拦截的站点，会自动在后台打开标签页签到（静默打开再关闭，不影响你使用）
- 下次签到时间显示在弹窗标题旁

### 4. Telegram 通知

在「通知」标签页填写：
- Bot Token：Telegram 找 @BotFather，发 /newbot 获取
- Chat ID：Telegram 找 @userinfobot，点 Start 获取
- 勾选「启用通知」，点保存
- 可以点「发测试」验证

签到完成后会推送结果到 Telegram，账号名自动脱敏。

## 特点

- ✅ 支持 Turnstile 人机验证站点（自动用浏览器标签页签到）
- ✅ 支持 Cloudflare WAF 拦截站点
- ✅ 多站点管理，支持编辑/删除
- ✅ 每天随机时间签到，防检测
- ✅ Telegram 推送签到结果（含获得额度和余额）
- ✅ 签到记录可查
- ✅ 纯本地运行，数据存在浏览器本地，不上传任何服务器

## 注意事项

- 浏览器需要保持运行（扩展依赖浏览器，关闭浏览器后定时任务不会执行）
- 如果电脑睡眠，唤醒后会检查是否错过签到时间，错过则当天不再补签
- 系统访问令牌如果失效，重新生成后在扩展里编辑更新即可
